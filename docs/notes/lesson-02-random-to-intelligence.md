1. Why does learning start with random numbers?

Because Learning can't start with 0 as for learning randomness is very necessary so that every learning is different from each other.

2. Why can't all weights start with the same value?

Because if we start all weights with the same value then the output will be the same for all of the outputs and learning will take place

3. What is a parameter?

A parameter is a number or an entity and the goal is to find the correct value reducing the error and learn at every step.

4. What is a model?

A model is a collection of parameters and a mathematical formulation of the parameters.

5. What is loss?

A loss is simple how much far we are from the correct value or the best possible output.

6. Why is loss necessary?

The loss is very necessary as without the loss we can't achieve the best possible output because loss we can't see where we are loosing behind.
