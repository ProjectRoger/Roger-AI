1. Why did the perceptron fail on the XOR problem?

The Perceptron fail on the XOR problem because It was only capable to capture linear relationships and XOR has non-linear relationship.

2. What is a linear relationship?

A linear relationship is there when we can draw a straight line between the inputs to specify the relationship.

3. Why doesn't stacking linear layers solve the problem?

Stacking Linear Layers does not solve any problem as if you stack multiple linear layers on top of each they will combinely become a linear layer only.

4. What is non-linearity?

Non - linearlity is something which can't be defined using a straight line, it is defined by a curve or any other diagram.

5. Why are activation functions essential?

The activation functions are essential as they help us to capture the non linear relationship present between the inputs.

6. Compare Sigmoid, Tanh, ReLU, and GELU in one or two sentences each.

Sigmoid is used to bound the output between 0 and 1.
Tanh is used to bound the output between -1 and +1 and centered around 0
ReLU is simple in which negative is blocked and the positive is move forward.
GeLU is smaller than ReLU but used in GPT models.
