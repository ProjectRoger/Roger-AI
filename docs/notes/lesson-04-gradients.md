1. What is a gradient?

Gradient is a entity or value which tells us to go in which direction to reduce the loss.

2. Why is a gradient more useful than just knowing the loss?

The Gradient is more useful than just knowing the loss as it helps to move in the best direction possible to reduce the loss we already know.

3. Why do we move opposite the gradient?

We move opposite the gradient because by that we move to reducing the loss to attain the best solution.

4. What does a positive gradient mean?

Positive gradient means As Weight increases the Loss is also increading.

5. What does a negative gradient mean?

Negative Gradient means As Weight is increasing Loss is decreasing.

6. What does a gradient close to zero suggest?

The gradient close to 0 suggest that even the value of the Weight Changes the Loss is not chnaging or becoming costant.
