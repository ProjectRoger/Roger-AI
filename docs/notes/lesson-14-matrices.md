1. What is a matrix?

When we keep n numbers of vectors it creates a matrix.

2. Why can a matrix represent multiple neurons?

Because matrix has the capability to store multiple neuorns vectors.

3. What does Wx mean?

W stands for the Weight Matrix of the neurons and x stand for the inputs.

4. Why must matrix dimensions match?

The matrix dimensions must match in order to carry out the required matrix operations.

5. What does a bias vector represent?

A bias vector is a group of numbers which is added to the weighted sum of the matrix weights and inputs in order to change the decision boundary.

6. What does y = f(Wx + b) mean?

Here, y defines the Output, W is the Weight Matrix, x is the inputs b is the bias and f interprets the activation function. This is a classic neural network equation.

7. How do you calculate the number of parameters in a layer?

The number of parameters for a layer is calculated as follows:

For inputs = 3, neurons = 4, bias = 3
The parameters = inputs * neurons + bias = 3 * 4 + 3 = 15

8. Why are matrix multiplications so important to AI?

The matrix multiplications is very important to AI as it helps to calculate large of vectors of the neurons very easily which helps for the accurate output required by an AI.

9. Why are GPUs particularly useful for neural networks?

GPUs are particularly useful for neural networks as it helps in the parallel processing of the large mathematical operations over CPUs which operates process by process.
