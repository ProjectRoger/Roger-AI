1. What is generalization?

Generalization is when the model is able to give the output or answer on the questions it has not seen.

2. Why isn't training accuracy enough?

The Training accuracy is not enough because sometimes the model memorizes the data and does not learn the data so to get this thing we can't depend on training accuracy alone.

3. What is the purpose of the training set?

The purpose of training set is to train the model which help to learn the patterns for future predictions.

4. What is the purpose of the validation set?

The purpose of validation set is to check how good the model is performing currently.

5. What is the purpose of the test set?

The purpose of test set is to get the predictions by applying the model on the set.

6. Explain underfitting in your own words.

Underfitting happens when the model does not learn the patterns even on the seen data.

7. Explain overfitting in your own words.

Overfitting happens when the model perfectly runs on the seen data but fails on the unseen data.

8. What is the difference between bias and variance?

Bias is the deifference between the predictions between the training data and test data.
Variance is the variability of the model for a given data point when trained on different datasets.
