# Roger

> Building a modern AI system from first principles.

Roger is a long-term research and engineering project dedicated to understanding and implementing every major component of modern AI systems.

The objective is not to clone ChatGPT, Claude, or Gemini, but to understand how such systems work by building each layer from scratch.

---

## Vision

Build a complete AI platform including:

- Neural Networks
- Automatic Differentiation
- Transformers
- Large Language Models
- Training Infrastructure
- Inference Engine
- Chat Platform
- Tool Calling
- AI Agents
- Coding Assistant
- Multimodal AI

---

## Philosophy

No black boxes.

If Roger uses something, Roger understands it.

Every algorithm, every architecture decision, and every experiment is documented and implemented from first principles whenever practical.
